My agents need a shared context

My agents have a task board. They also need a shared context.

In my last post I wrote about giving them Trello accounts. But knowing who is doing what is only part of working as a team.

People use Confluence or Google Docs to keep the things everyone needs to know. How we work, our policies, our projects, the workflows we follow. You don’t explain all of that again every time someone picks up a task.

I want the same for my agents.

The screenshot is a “company brain” I created in GitHub for the agents to work with. You can see folders for identity, product, memory, onboarding, operations, flows and references.

It’s more than remembering things. It’s also a place to write down how the organisation works. I think of it as an operating system for the organisation.

Think shared Confluence, with markdown files and scripts. For this particular use, that’s the format I prefer. Different AI tools can work from the same material rather than whatever I happened to tell each one in a chat.

The work for me is deciding what belongs there, how to organize it, and what changes I’m happy with. I need to understand the basic setup and access. The agents can handle the Git operations.

It still needs looking after. Files get outdated, edits can conflict, and a shared folder doesn’t make everyone follow the rules.
